# WaterGEMS ModelBuilder Tool V3.4.3

## Menu Camadas
O menu de tipos do mapa agora usa um QMenu customizado.

Ao marcar/desmarcar ações checkáveis:
- o dropdown permanece aberto;
- é possível alterar várias camadas em sequência;
- clicar fora fecha o menu normalmente.

## Atualizar região visível
Limites ampliados:

- até 40.000 geometrias examinadas;
- até 25.000 geometrias carregadas;
- até 10 segundos de processamento.

Se qualquer limite for atingido antes de concluir a busca, o mapa anterior é
preservado e a aplicação recomenda aproximar o zoom ou aplicar um filtro.
