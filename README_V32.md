# WaterGEMS ModelBuilder Tool V3.2

- Nome dos Selection Sets: tenta primeiro HMIModelingElement.ElementID = SelectionSetID e usa Label.
- "Todos os elementos": visão conjunta de Pipe, Junction, válvulas, tanques, bombas etc., com coluna Core.Type.
- Filtro avançado com AND/OR/parênteses e sintaxe SQL simplificada.
- `%` funciona como wildcard: `ABC%`, `%ABC`, `%ABC%`.
- Lista de campos com duplo clique para inserir no editor.
- Amostra parcial e valores únicos completos para inserir valores existentes.
- Ctrl/Shift selecionam linhas visualmente; Space ou botões explícitos marcam/desmarcam checkboxes.
- Painéis redimensionáveis por QSplitter.
- Colunas da tabela usam largura Interactive e podem ser ajustadas manualmente.
