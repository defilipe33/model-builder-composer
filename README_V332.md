# WaterGEMS ModelBuilder Tool V3.3.2

Mapa:

- linhas usam `QPen.setCosmetic(True)`, portanto a espessura visual fica fixa em pixels;
- rede normal: 1 px;
- selecionados: 4 px por padrão;
- espessura dos selecionados ajustável entre 1.5 e 10 px;
- checkbox `Mostrar apenas selecionados`;
- quando esse modo está ativo, apenas os elementos do SelectionSet permanecem visíveis;
- zoom não altera a largura visual das linhas.
