# WaterGEMS ModelBuilder Tool V3.6.2

## Legenda do mapa

A legenda agora é uma camada de interface fixa e não faz parte da cena gráfica.

Portanto:
- zoom não move a legenda;
- pan não move a legenda;
- ela permanece presa ao canto inferior direito do painel do mapa.

## Recolher / expandir

A legenda possui um botão no cabeçalho.

Expandida:
- mostra todos os símbolos e descrições;
- botão `−` recolhe.

Recolhida:
- ocupa apenas um pequeno botão `Legenda`;
- clicar nele expande novamente.

A simbologia continua sendo atualizada dinamicamente conforme as regras
configuradas pelo usuário.
